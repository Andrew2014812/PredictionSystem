## Выводы

- Да, после v6 FootPredict действительно называет ничьи: доля названных ничьих 0.0 %–0.3 % → 21.1 %–32.8 % (факт ≈25–27 %), полнота ничьих 0.0 %–0.2 % → 25.1 %–38.5 % при точности 28.3 %–31.2 %, macro F1 0.362–0.369 → 0.435–0.445 на всех сезонах, включая независимый 2026/27. Цена — accuracy ниже на 1.3–3.3 п.п.; balanced accuracy выше на 0.6–2.4 п.п. Вероятности (log loss, Brier) не изменились.
- Ничья не становится Main из-за правила Main, а не из-за модели: P(D) не превышает 0.390 (порог Main 0.40), средний коэффициент ничьей 3.73–3.87 лежит вне окна 1.40–2.50 (множитель odds_preference 0.11–0.13), а оценка Main пропорциональна вероятности: даже без порога, штрафа за коэффициент и с максимальным бонусом EV потолок оценки ничьей (0.29–0.30) ниже средней оценки выбранного Main (0.59–0.68); в walk-forward-блоках Main ни разу не оказался ниже этого потолка, в истории 2026/27 — в 1.4 % матчей. Ничья часто становится Risk (31.3 %–60.2 % матчей).
- Ни один новый способ получения вероятностей не улучшил log loss убедительно (лучший допущенный — e_xgb_mnl, Δ log loss на отборе -0.40·10⁻³, CI включает 0). Букмекер (Bet365 без маржи) лучше модели на 0.0135 по log loss 1X2, но по бинарному log loss ничьей лишь на 0.0015: преимущество рынка — в П1/П2, а не в ничьих.
- Ничья как Main не даёт устойчивого выигрыша: лучшая на отборе политика t0.28_g1.00_e0.05 меняет ROI Main на +0.6 п.п. [-0.6; +1.9] п.п. на отборе и на -0.2 п.п. на 2025/26; интервалы включают ноль. Плоская ставка на каждую ничью убыточна (ROI -3.3 %, -5.9 %, -4.1 %, -9.4 %, -9.8 %). Продакшн не меняется.
- Текущее правило назначения (t = 0.28, g = 0.20) повторно выбрано тем же критерием (thr_t0.28_g0.20); более сильного правила по заранее заданным критериям не найдено.
