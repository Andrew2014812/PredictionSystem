## Решение

- Лучший по log loss 1X2: ens_all. Ни один вариант не получил A: ROI Main значимо не меняется (Холм), а выигрыш метрик мал относительно разрыва с рынком; замена XGBoost потребовала бы новой зависимости и переобучения всех задач — production не меняется.
- B (форвард-проверка): ens_xgb_best, best_per_task.
- Кандидаты B — только форвард-проверка (`results/preregistration.json`). Если форвард-проверка подтвердит выигрыш по голам хозяев, изменение production было бы таким: в `src/modelling/pipeline.py` обучать для задачи home_goals вторую модель — Poisson GLM (`PoissonRegressor`, alpha из `results/selection.json`, медианная импутация с индикаторами + стандартизация) на тех же признаках — и усреднять её λ с XGBoost; остальные задачи без изменений.
