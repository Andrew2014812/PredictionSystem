# FootPredict v6.3 — исследование угловых: выводы

Все числа — из `results/results.json` (файл собирается `build_pdf.py`). PDF: `reports/v6_3/Corners_Research.pdf`.

## Результаты

- Новые признаки работают на сезоне выбора: на 2025/26 девиацию Пуассона значимо (Holm p < 0.05) снижают 7 моделей (XGBoost + новые признаки, XGBoost + новые + рынок, LightGBM, CatBoost, Poisson GLM, Ансамбль (веса 2025/26), Ансамбль (равные веса)); лучшая — Poisson GLM, Δ -0.0078 [-0.0128; -0.0025].
- На 2026/27 улучшение сохраняется по точке у 9 моделей, но значимо — у 0 (ни одной): выбранная Poisson GLM — MAE 2.712 против 2.727, R² 0.043 против 0.040, Δдевиации -0.0038 [-0.0135; +0.0057]. Выигрыш ~0.3–0.5 % девиации — того же порядка, что и в v6.1: потолок предсказуемости угловых низкий.
- Динамические рейтинги как самостоятельная модель хуже продакшна (Δдев. 2025/26 +0.0180 [+0.0078; +0.0283]), полезны лишь как признаки.
- Раздельные модели хозяев и гостей не лучше одной модели суммы (2025/26 Δ -0.0018 [-0.0061; +0.0025]). Копула Франка: θ = 0.218, τ Кендалла = 0.024 — при известных средних угловые сторон почти независимы; отрицательная безусловная корреляция объясняется средними (доминирование одной команды), и свёртка не даёт выигрыша над одним NB.
- Дисперсия: r продакшна 71.1, ML на 2025/26 для продакшн-μ 64.5, COM-Пуассон ν = 0.867. Все NB / NB-P / COM-Пуассон / NB по лигам отличаются от продакшна на 2026/27 в пределах -0.0004…+0.0009 log score (незначимо); только Пуассон значимо хуже (+0.0062 [+0.0021; +0.0103]). Распределение продакшна адекватно, менять его нет смысла.
- Калибровка линий (Платт / изотоническая) на 2025/26 не улучшает перекрёстный log loss (platt: 0.6673 против 0.6669 без калибровки) — вероятности тоталов уже откалиброваны (ECE ≤ 0.035).
- Выбранный на 2025/26 вариант Poisson GLM + NB, r по лигам: Δlog score к продакшну на 2026/27 -0.0005 [-0.0049; +0.0041], Δ log loss линий -0.0008 [-0.0038; +0.0021]; ансамбль -0.0010 [-0.0051; +0.0032]; ежемесячное переобучение -0.0006 [-0.0051; +0.0039].
- Против рынка (bet365 без маржи, close): log loss 8.5: рынок 0.6505, продакшн 0.6512, лучший 0.6512; 9.5: рынок 0.6810, продакшн 0.6815, лучший 0.6802; 10.5: рынок 0.6616, продакшн 0.6614, лучший 0.6603 — модели на уровне рынка, устойчивого перевеса нет.
- Ставки на угловые (close, EV ≥ 0): продакшн ROI -2.0 % [-7.8; +4.1] на 2750 ставках, выбранный вариант -1.0 % на 2064; ни одна стратегия ни одного варианта не имеет ДИ выше нуля.
- Main (close): угловые выбираются редко (продакшн — 15 из 2250 матчей); ΔROI выбранного варианта к Baseline B +0.01 [-0.33; +0.35] п.п., Holm p = 1.000; без угловых вовсе -0.13 [-0.49; +0.21] п.п.
- Main (t09): угловые выбираются редко (продакшн — 112 из 2250 матчей); ΔROI выбранного варианта к Baseline B +0.12 [-0.79; +1.07] п.п., Holm p = 1.000; без угловых вовсе -0.10 [-1.10; +0.88] п.п.

- **best_wf** (Poisson GLM, ежемесячное переобучение + NB, r по лигам): B — перспективно, форвард-проверка
- **ens** (Ансамбль (веса 2025/26) + NB, r по лигам): B — перспективно, форвард-проверка
