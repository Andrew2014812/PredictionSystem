## Главное

- Лучший по правилу вариант — Смесь XGB + Махер + согл.: Δ log loss счёта -1.88 [-2.91; -0.81] ×10⁻³ (p Холма 0.013; текущий log loss 2.9026); по сезонам 2023/24 -2.01, 2024/25 -1.76, 2025/26 -0.81, 2026/27 +0.02. При этом ROI Main ниже: -1.4 п.п. [-2.5; -0.2].
- Контроль — перекалибровка средних XGB без рейтингов: +0.52 [+0.09; +0.97] ×10⁻³ — выигрыш смеси даёт информация рейтингов, а не сжатие средних.
- Согласование с 1X2 — главный источник качества: сырой Пуассон хуже текущего на +1.17 [-0.12; +2.43] ×10⁻³; сырая версия хуже согласованной у 11 из 11 семейств.
- Семейства распределения при тех же средних (после согласования) отличаются от текущего на Диксон–Коулс + согл. +0.09, Бивариантный Пуассон + согл. -0.01, Отр. биномиальное + согл. +0.10, Конвей–Максвелл–Пуассон + согл. -0.06, Копула Франка + согл. +0.04, Франк + КМП + согл. -0.02 ×10⁻³ — в пределах ±0.1 и без значимого выигрыша (BP с λ₃ = 0 совпадает с текущим).
- Передисперсии нет (α хозяев -0.030, гостей -0.018; NB вырождается в Пуассон); 0-0: факт/ожидание 1.037 (p = 0.12) — инфляция нулей не оправдана; избыток ничьих 1.081 снимается согласованием.

## Код продакшна

- Скрытая ошибка (флаг `DIXON_COLES = False`, сейчас не действует): `pipeline.py` подбирает ρ по сырым средним, `engine.py` применяет ρ до согласования с 1X2. ρ пайплайна по сезонам -0.014, -0.056, -0.027, -0.054; оптимальное после согласования +0.019, -0.008, +0.025, +0.001; Δ log loss счёта с ρ пайплайна -0.01 [-0.19; +0.19], +0.93 [+0.18; +1.72], +0.11 [-0.25; +0.47], +0.30 [-1.01; +1.56] ×10⁻³. Исправление при включении: подбирать ρ по согласованной матрице.
- Складывание хвоста > 10 голов в ячейку 10 — не ошибка (эффект ~1e-5).

## Решение

- A: нет — оставить «Пуассон + согласование с 1X2» (rho = 0).
- B: Смесь XGB + Махер + согл. — предрегистрация `results/preregistration.json`, форвард-проверка
- C: остальные варианты; инфляция нулей и NB не нужны (данные не передиспергированы); Диксон–Коулс (ρ ≈ 0 после согласования) оставить выключенным.
- Продакшн не меняется исследованием.
