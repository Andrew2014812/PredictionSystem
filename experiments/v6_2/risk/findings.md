## Почему EV > 0, а ROI < 0

- EV по цене рынка без маржи совпадает с фактом (рынок − факт: ДИ содержит 0 во всех сезонах); EV модели выше на +8.0, +7.9, +7.0, +15.8 п.п. по сезонам.
- Кандидаты пула откалиброваны; выбранный Risk переоценён (+2.7 п.п. 2023/24, +5.9 п.п. 2026/27) — эффект выбора; растёт с размером пула.
- Фаворит–аутсайдер: исходы с коэффициентом ≥ 4.5 теряют больше маржи; модель завышает их сильнее рынка.

## Правила

- Лучшее по зафиксированному правилу: v6.1: стек с рынком, пол EV ≥ 0, ΔROI объединённо +1.8 [-0.8; +4.3], p Холма 1.000 — не перспективно по критерию; знак положителен во всех сезонах.
- Ранжирования по EV/Келли/нижней границе/перевесу и сокращение числа ставок — без устойчивого улучшения.

## EV с возвратом

- Формула продакшна для целых линий верна (макс. расхождение 5e-07); четвертных линий нет (0 из 26795 котировок).
- Ошибка: `effective_odds`/`fair_odds` = 1/p для целой линии без цены; верно (1 − p_refund)/p. Меняет Risk в 2023/24: 82, 2024/25: 60, 2025/26: 42, 2026/27: 0 матчах (все — выборы без цены).

## Решения

- A: исправить эффективный коэффициент целой линии (отдельным изменением кода).
- B: v6.1: стек с рынком, пол EV ≥ 0; Вероятность Risk = вероятность рынка без маржи — форвард-тесты (`results/preregistration.json`).
- C: остальные ранжирования, сокращение ставок, показ EV модели как преимущества.
