## Исследование
- **Скользящие признаки корректны:** независимый пересчёт из сырых CSV дал 0 расхождений на 38 266 матчах × 37 признаках (1 415 842 значения). Построитель признаков воспроизводит production побитно.
- **Данные API совпадают с Football-Data:** 0 из 457 счетов и 0 из 791 времени начала расходятся, перепутанных хозяев и гостей нет.
- **Обнуление признаков одной команды** («клуб без истории») на 23 672 матчах:
  - хозяева: log loss +57.4·10⁻³ [53.5; 61.5], Main меняется в 74 % матчей;
  - гости: log loss +35.5·10⁻³, Main меняется в 66 %;
  - ROI Main ни в одном из 13 вариантов значимо не меняется.
  - Фантомные прогнозы воспроизводятся этим обнулением точно.
- **Клубы из незагружаемых лиг:**
  - первые 10 матчей сезона: log loss +63.8·10⁻³ [34.6; 92.8], но против рынка +10.4·10⁻³ [−4.7; 25.2] — шум;
  - ROI Main по всем их матчам −9.9 % [−15.1; −4.8] против −3.4 % у матчей устоявшихся клубов;
  - в первых 3 матчах модель переоценивает их на +0.217 ожидаемых очков [+0.050; +0.380].
- **Оценка качества данных матча** (доля пустых признаков) почти не связана с ошибкой: Spearman 0.022.
