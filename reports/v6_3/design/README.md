# FootPredict v6.3 — выбор индикатора результата Main на странице Matches

Индикатор показывается только у завершённого матча, у которого есть рассчитанный Main из истории сайта
(live или backfill — одинаково, та же единая история, что и в Prediction History): WON, LOST или PUSH (возврат).
Для несыгранного, отменённого (VOID) матча и матча без прогноза индикатора нет.

Скриншоты настоящей страницы Matches (08.11.2026), обе темы, 1920×1080 и 1366×768: `main_mark/<вариант>_<тема>_<размер>.png`
(`python scripts/ui_main_mark_variants.py`). Варианты отличаются только CSS.

| Вариант | Вид | Читаемость | Место | Сочетание с карточкой | Тёмная / светлая | 1366×768 | Понятность |
|---|---|---|---|---|---|---|---|
| A — текст | «MAIN WON» цветным текстом | средняя: мелкий текст без фона теряется рядом с коэффициентами | мало | спокойно, но сливается с подписями | обе читаются | да | хорошая |
| B — иконка + подпись | ✓ / ✕ / ↺ и «MAIN» | статус только иконкой и цветом | очень мало | хорошо | обе | да | средняя: «MAIN ✕» можно принять за отсутствие прогноза |
| C — цветная плашка | плашка «MAIN WON» без иконки | высокая | среднее | плашка отделена от чисел | обе | да | хорошая, но статус передаётся цветом и словом, без формы |
| D — плашка, иконка + «MAIN» | компактная плашка | высокая, но статус без слова | мало | хорошо | обе | да | средняя: нужно знать значение иконок |
| **E — плашка, иконка + текст** | **плашка «✓ MAIN WON» / «✕ MAIN LOST» / «↺ MAIN REFUND»** | **высокая** | **среднее (≈ 95 px)** | **отделена от коэффициентов и вероятностей, не спорит со счётом** | **обе** | **да** | **лучшая** |

**Выбран E.** Слово MAIN и статус прямо говорят, что это результат основного прогноза, а не победитель
матча (победитель уже выделен жирным счётом слева). Цвет, иконка и слово дублируют друг друга, поэтому статус
различим и при нарушениях цветового зрения. Плашка стоит в отдельной колонке у правого края карточки и не
сдвигает существующие блоки; подсказка при наведении расшифровывает статус («Main prediction refunded (push): the
stake is returned»). Контраст текста плашки проверяется аудитом `scripts/ui_contrast_audit.py`.
